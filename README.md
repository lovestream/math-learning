## 使用

在 macOS 上双击 `start.command`。程序会完成本地构建、启动后台服务并打开：

```text
http://127.0.0.1:4177
```

关闭终端或启动窗口后服务仍会继续运行。需要停止时双击 `stop.command`，或者在终端运行它。日常运行不需要互联网。

开发模式：

```bash
npm run dev
```

## 当前课程

- 数与运算：位值、数轴加减、乘法阵列、除法与余数
- 数量关系：等号、和差、和倍、差倍
- 图形与几何：周长、面积、植树问题、火柴棒拼图
- 规律：奇偶、周期余数、首尾配对、年龄差不变
- 逻辑与计数：系统枚举、鸡兔同笼、倒推、抽屉思想
- 分数与时间：分数意义、比较、等值分数、时分秒
- 四年级：大数、估算、角、两位数乘除、运算律、平行四边形与梯形、面积单位、条形统计图；奥数含鸡兔同笼、路线枚举、周期余数、倒推、抽屉原理
- 五年级：小数乘除、等值分数、组合面积、长方体体积、方程、坐标、可能性、因数质数、图形运动；奥数含整除筛选、树状计数、平均数优化、面积不变量、工作效率
- 六年级：分数乘除、比、百分数、圆、扇形统计图、负数、圆柱体积、比例、代数表达；奥数含组合计数、极端法、奇偶不变量、行程比例、几何变换

地图和家长中心都可以直接选择年级；三年级的先修关系只显示为推荐提示，不会把关卡变灰或阻止进入。审计课程源在 `content/course-plan-v2/grade-3.json`，互动运行包由 `content/pilot/` 生成；四至六年级旧课程源继续保留。教材PDF只作为本地研究资料使用，`research/source-textbooks/` 不提交到GitHub；`data/` 只保存本机运行数据与备份。

课程直接加入教材单元地图、“今天”、复习站和错题入口，没有单独的“样板课堂”菜单。每个三年级单元呈现 B 基础→E 提升→O 思想，并列出来源、建议先修和 R 到期复习；默认展开最近学习的单元。练习题库按小组使用，核心每组3–5题，不要求一次做完全部题库。

三年级70个入口采用六屏短课堂，原五课能拖动相机、追踪积木投影、连续折纸、拖物品上秤、调天平与按水线替换模型象。可查看家长完整教案，已接入原有精确折纸模板打印。正式题组沿用已审定题ID和判分；解释题仍需家长核对，操作不直接获得学习积分。

练习保存首答、三项自查勾选、终答、提示与订正；“已探索”“已练习”“独立迁移与延迟复习达标”分开显示。逐题编写的结论与证据题必须分别回答。尚未配置可靠自动判分的解释题保存为待家长核对，不计为答对或发积分；正式练习中的待核对解释题仍不自动结算。17张迁移卡另有家长批阅工作台：保留首答、帮助、自查、终答和更正历史，批阅不发积分；独立通过、辅助订正、需要回补、暂缓判断分别安排复习。

权威来源：`content/course-plan-v2/grade-3.json` 是教案源，`content/pilot/source.mjs` 和专项响应规格是运行编译源，`content/pilot/lessons.json` 与 `content/rollout.json` 由构建生成。旧 rollout 已归档到 `docs/history/`。观察物体／质量五课的响应版本为 `2026-10-07.2`，其余保持 `2026-10-02.1`，既有课题 ID、历史作答与积分流水保留；跨版本不会重复领取同题基础积分。角色素材来源可追溯，但仓库未附可核验的再分发授权，不能视为开放许可证，详见素材清单。

## 数据与备份

学习记录存放于 `data/progress.sqlite`。家长中心可一键导出全部进度，导入时会先校验格式、内容和积分流水，然后自动备份当前进度并在一个事务中导入。每日首次写入也会在 `data/backups/` 保存备份。

家长首次进入迁移批阅工作台时设置6–12位数字密码。离开家长中心或关闭页面会锁定，解锁最多30分钟；服务重启需重新解锁。密码以加盐哈希保存在本机 `data/parent-access.json`，不随进度导出。

导出的 JSON 包含课程版本、逐次作答、迁移卡原始及历次复习证据、批阅历史、错题线索、复习到期时间、积分流水、宠物和物品。不要手工修改校验字段；需要迁移时直接在家长中心选择文件。
