# Kevin Math Lab · 数学探险岛

面向 Kevin 的本地数学实验室。课程参考人教版教材结构，重点是“现实问题→图形模型→符号语言→规律与方法→自己复述”。三年级现有70节可自由进入的课程入口、849道任务，其中审计主线为60课、720题；另保留从数数开始的基础入口和链环、木板搭接、点与间隔等精修扩展课。四至六年级旧课程包仍在项目中，本轮保持冻结，没有把旧内容冒充新版精修课。最新一轮以观察物体和质量／曹冲称象五课为第二代交互样板，见 [新一轮审计回应](docs/review/新一轮审计回应与验收_20261007.md)；上一轮编译与混合运算修复见 [历史审计回应](docs/review/审计回应与验收_20261007.md)。历史实现记录见 [三年级课程接入记录](docs/Kevin_数学设计深化优化_20260925/09_三年级完整互动课程实现与验收_20260928.md)。

最新动画复查见 [立体与动画验收报告](docs/review/动手实验立体与动画复查_20261007.md)：六面纸盒连续折叠／暂停／旋转，29个现有实验逐项检查。静态关系卡入口明确标为“画图想一想”。
蛋仔家园是学习的陪伴层：咚咚羊作为欢迎伙伴加入，蜜蜂 DongDong、鸭鸭 DongDong 可用学习积分邀请；学习关卡、到期复习和思维训练分别会留下共同回忆、成长值和当天约定礼物。可以点伙伴对话、摸摸、喂食、拖拽零食、接星星小游戏、布置三种小屋场景，并在“我们的回忆”里看到一起想明白过的知识。养成不衰减、不因离线惩罚，也不能靠重复点击刷学习积分。

角色图片和短原声使用《蛋仔派对》官网公开素材，未使用生成式图片或合成角色声音；素材来源、截取时间和处理方式记录在 `research/pets/assets-manifest.json`。原声按钮只在 Kevin 主动点击时播放，浏览器不会自动出声。

## 使用

在 macOS 上双击 `start.command`。程序会完成本地构建、启动后台服务并打开：

```text
http://127.0.0.1:4177
```

关闭终端或启动窗口后服务仍会继续运行。需要停止时双击 `stop.command`，或者在终端运行它。日常运行不需要互联网。

开发模式：

```bash
npm run dev
```

## 当前课程

- 数与运算：位值、数轴加减、乘法阵列、除法与余数
- 数量关系：等号、和差、和倍、差倍
- 图形与几何：周长、面积、植树问题、火柴棒拼图
- 规律：奇偶、周期余数、首尾配对、年龄差不变
- 逻辑与计数：系统枚举、鸡兔同笼、倒推、抽屉思想
- 分数与时间：分数意义、比较、等值分数、时分秒
- 四年级：大数、估算、角、两位数乘除、运算律、平行四边形与梯形、面积单位、条形统计图；奥数含鸡兔同笼、路线枚举、周期余数、倒推、抽屉原理
- 五年级：小数乘除、等值分数、组合面积、长方体体积、方程、坐标、可能性、因数质数、图形运动；奥数含整除筛选、树状计数、平均数优化、面积不变量、工作效率
- 六年级：分数乘除、比、百分数、圆、扇形统计图、负数、圆柱体积、比例、代数表达；奥数含组合计数、极端法、奇偶不变量、行程比例、几何变换

地图和家长中心都可以直接选择年级；三年级的先修关系只显示为推荐提示，不会把关卡变灰或阻止进入。审计课程源在 `content/course-plan-v2/grade-3.json`，互动运行包由 `content/pilot/` 生成；四至六年级旧课程源继续保留。教材PDF只作为本地研究资料使用，`research/source-textbooks/` 不提交到GitHub；`data/` 只保存本机运行数据与备份。

课程直接加入教材单元地图、“今天”、复习站和错题入口，没有单独的“样板课堂”菜单。每个三年级单元呈现 B 基础→E 提升→O 思想，并列出来源、建议先修和 R 到期复习；默认展开最近学习的单元。练习题库按小组使用，核心每组3–5题，不要求一次做完全部题库。

2026-10-07 审计修改：删除根据题干抓数字的伪模型和能靠文字猜答案的自动选项。混合运算增加六类有明确参数的提升／思维实验，选择运算、填写中间量、切分点阵、比较退款路线和倒推都保留实际操作记录。当前运行包中22课配置专用模型，41课明确使用待审阅的静态关系卡，另有7课使用既有基础组件；不能把70个入口等同于70课均已完成教学验收。

五课采用六屏短课堂，能拖动相机、追踪积木投影、连续折纸、拖物品上秤、调天平与按水线替换模型象。可查看家长完整教案，已接入原有精确折纸模板打印。每课核心3题、迁移2题、复习4题均有可靠响应判定，核心有逐题自查；操作不直接获得学习积分。

练习保存首答、实际自查动作、终答、提示与订正；“已探索”“已练习”“独立迁移与延迟复习达标”分开显示。逐题编写的结论与证据题必须分别回答。尚未配置可靠自动判分的解释题保存为待家长核对，不计为答对或发积分；家长中心可查看回答和参考过程，目前尚无家长核准后结算接口。

权威来源：`content/course-plan-v2/grade-3.json` 是教案源，`content/pilot/source.mjs` 和专项响应规格是运行编译源，`content/pilot/lessons.json` 与 `content/rollout.json` 由构建生成。旧 rollout 已归档到 `docs/history/`。观察物体／质量五课的响应版本为 `2026-10-07.2`，其余保持 `2026-10-02.1`，既有课题 ID、历史作答与积分流水保留；跨版本不会重复领取同题基础积分。角色素材来源可追溯，但仓库未附可核验的再分发授权，不能视为开放许可证，详见素材清单。

## 数据与备份

学习记录存放于 `data/progress.sqlite`。家长中心可一键导出全部进度，导入时会先校验格式、内容和积分流水，然后自动备份当前进度并在一个事务中导入。每日首次写入也会在 `data/backups/` 保存备份。

导出的 JSON 包含课程版本、逐次作答、错题线索、复习到期时间、积分流水、宠物和物品。不要手工修改校验字段；需要迁移时直接在家长中心选择文件。
