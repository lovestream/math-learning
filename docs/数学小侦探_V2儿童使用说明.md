# 自己解、自己查

先选一个你正在学的数学题族。每次做一小题就可以暂停，不用一天完成四层训练。

- 想看看别人的做法：打开错例和正确对照。先判断，再逐行找证据。没有中间步骤，就说信息不足，不猜别人是怎么想的。
- 想自己试：点“自己解一题”。写第一次答案，可以补一句思路；不会做也能如实保留空白或不确定。
- 首答保存以后，先不看对错。把自己的答案代回题目条件，亲自算一次反查结果，并留下你实际算过的检验式。交换乘法顺序、拆括号、分开计算都可以；也可用□代表自己的答案。发现问题可以改，没发现问题也可以保留原答。
- 只抄题目里的核对值，不能说明已经做过检验。其他方法可以写在解释里，先保存为待核对，请家长检查原记录。
- 第二次答案和检查过程一起提交以后，才会出现反馈。第一次错、自己改对，也是一条有用的事实；第一次对却改错，同样会保留。
- 需要帮助可以打开提示、条件图或请家长解释。记录会说明用过什么帮助，不会因此删掉你的成果。
- 过几天“做今天到期的新题”会出现。它不会再给你预填反查算式，请自己写一条。到期提醒不是必须今天全部做完，家长可以暂停或顺延。

检查不是为了每次都改答案，而是看看自己的结果能不能满足原题。不会因为选“完成检查”就自动算对，也不会因为这一题正确就说你永远掌握了。

看见“记录已保存在本机”再暂停。断网或有保存冲突时，输入仍在本页；先重试或下载草稿，再载入最新记录，不要强制关闭未保存页面。
