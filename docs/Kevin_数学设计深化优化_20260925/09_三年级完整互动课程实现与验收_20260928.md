## 2. 从课本主线向外生长

课程按“课本主线 → 本章提升 → 思维挑战”组织。课本提供知识发生的先后关系，提升课继续追问同一个模型，奥数课研究模型中的不变量、逆向关系和一般规律。

例如混合运算不再停在“先括号、再乘除、后加减”：

1. 基础课先用珠子、纸带和两步故事说明运算顺序记录的是现实中的先后关系。
2. 提升课继续研究去括号、添括号、连续除、交换律、结合律和分配律。
3. 思维课再用倒推流程与代换卡研究逆向思维和未知量。

长度测量则从刻度与单位出发，扩展到路线估测、木板搭接、链环接头和点与间隔。其他章节也采用同一组织原则。

## 3. 互动模型

除五种精修长度实验和原有混合运算实验外，本轮新增16类数学模型实验室：空间观察、运算结构、质量天平、位值、编码、线与角、分数、方案规划、图形变换、除法、边界、面积方格、数据、时间、小数和集合。

同一类内部也按课程内容切换模型，避免只换标题和文字：

- 混合运算分别使用运算轨道、盒装与散装、括号对照、纸带删减、中间量条形图、钱袋付出/退回、交换与结合点阵、分配律点阵、倒推流程和代换卡。
- 除法分别使用位值拆分、竖式四步、平均分与余数、商中间的0、包装层级和归一流程。
- 图形分别使用分类卡、外边界描线、拼接隐藏边与面积方格。
- 分数分别使用平均分纸带、物品整体和“先求1份”的数量模型。
- 统计、时间和小数分别加入区间边界、平闰年日历、钟面时间轴和数位对齐表。

实验统一要求 Kevin 先写预测，再按本课动作名称依次点击三张操作卡。每一步完成后，图形和说明同步变化；全部完成后才允许打开结果和原因。这样保留猜想、操作、观察和解释的顺序，不把结论预先送出。

## 4. 练习、自查与复习

每节审计课程固定为12题：热身2题、核心3题、迁移2题、挑战1题、独立复习4题。题图从当前题干提取数字与关系，练习图不再机械复制课上例题，也不会把完整答案画出来。

练习只在需要数值时填写数值，单位由题目和输入框给出；不再要求 Kevin 做无意义的单位选择。非数值问题提供三个“结论和理由”选项，错误项来自本课典型错法和对应数学模型，不再出现与当前知识无关的通用干扰项。

首答保存后，系统按16类模型提供不同的自查清单。例如：

- 混合运算检查括号、第一步和未计算部分是否原样保留。
- 分数检查整体、平均分、分子分母和实际数量。
- 除法检查平均分含义、数位、余数条件和乘法验算。
- 周长面积检查外边界与内部覆盖有没有混淆。
- 时间检查时刻、时长、跨日与起止边界。
- 集合检查重叠部分是否被重复计算。

最终错答才显示结构诊断，并进入统一错题修复和1、3、7、21天间隔复习；看过提示的当日订正不会冒充独立掌握。
