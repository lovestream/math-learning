# 三年级长度测量样板：实现与验收记录

更新日期：2026-09-27  
内容版本：`2026-09-27.1`

## 1. 本轮目标与边界

本轮把三年级“长度测量”做成可真实学习的完整样板，验证“课本主线 → 本章提升 → 思维挑战”的组织方式，以及“理解 → 实验 → 自查 → 分层练习 → 错因诊断 → 间隔复习”的完整闭环。

本轮完成的是长度单元的五节精修课，不代表三年级全部章节都已达到同一精修深度。四至六年级课程源文件未修改。

## 2. 五节课程与主线关系

| 层级 | 课程 | 要解决的核心问题 |
| --- | --- | --- |
| 课本主线 | 毫米、厘米、米：尺子量到的到底是什么 | 单位量、刻度、两端读数之差、断尺测量 |
| 课本主线 | 千米与估测：不是猜，而是拿已知长度去比较 | 千米与米、参照段、路线分段、估测校准 |
| 本章提升 | 木板搭接：相加以后，哪一段被算了两次 | 材料总长与成品跨度、重叠去重、逆向求重叠 |
| 本章提升 | 四个链环扣起来：一个接头为什么要看两段厚度 | 单位换算、接头数、每个接头的两段厚度、一般化 |
| 思维挑战 | 点与间隔：6段直路为什么有7个端点 | 点与段、直线与闭环、植树与路灯模型 |

每课不只给结论，还明确加入了：现实问题、概念怎样被发明出来、图中各量分别表示什么、为什么公式成立、怎样换一种方法复核，以及让 Kevin 自己复述的提示。

## 3. 互动实现

五种实验由同一套长度模型同时生成图形位置、操作反馈和正确答案，避免“图是一套、判分又是一套”。

- 尺子实验：移动小棒，观察零刻度起点、非零起点和毫米放大镜；结论是右端读数减左端读数。
- 千米路线：用 100 米或 200 米作参照段前进，比较分法改变时总路线是否保持不变。
- 木板搭接：拖动木板或使用滑杆改变重叠长度，实时观察端到端长度随重叠量变化。
- 链环连接：逐个加入链环，放大查看接头，确认一个接头沿长度方向少掉两段金属厚度。
- 点与间隔：在直线和闭环之间切换，实际“走过”每一段，区分段数和不同标记数。

实验统一采用“先预测 → 再动手 → 最后核对”。数量关系和推导只在 Kevin 主动核对后出现，避免先看到答案再机械模仿。

## 4. 练习、自查与复习

五课共 60 道分层任务，每课 12 道：热身 2 道、核心 5 道、迁移 2 道、挑战 1 道、独立复习 2 道。其中 28 道带有随题变化的测量图，且每课的迁移或复习组都保留可视化题，图形没有只集中在讲解和核心模仿题。

练习输入只填写数值，单位由题目和输入框明确给出，不再让 Kevin 额外选择单位。

提交分成两步：

1. 保存首答后进入“先当一次自己的小老师”，系统不显示对错，而是按题型给出三项检查。
2. 提交最终答案后才判分；答错只指出需要检查的数学结构，不直接泄露完整解法。

例如链环题的检查顺序是：单位是否统一、接头数是否为环数减一、每个接头是否包含前后两段厚度。错答历史仍进入错题修复和 1、3、7、21 天间隔复习；当日看过提示的订正不会冒充独立掌握。

## 5. 响应式与可读性

路线练习在宽屏显示分段路线，在窄屏改为“图中标第几段、图下逐段列出长度”。这样长地名和混合单位不会被裁掉，也不会要求孩子横向拖动才能读完整条件。

浏览器实测覆盖 1280 像素桌面视口和 390×844 窄视口；两者页面宽度均无横向溢出。窄屏底部导航、题干、路线图和分段说明可以同时使用。

## 6. 自动校验与人工验收

自动校验结果：

- 内容校验通过：18 节互动课、225 道任务。
- 全量测试通过：54/54。
- TypeScript 类型检查通过。
- Vite 生产构建通过。
- 长度模型测试覆盖链环、木板、断尺、路线、直线与闭环；新增约束保证每节长度课至少有 5 道可视化练习，并覆盖迁移或复习组。

浏览器人工验收结果：

- 地图正确显示“课本主线／本章提升／思维挑战”，提升课带有从本章基础继续追问结构的说明。
- 路线题在作答前只显示已知分段和“求整条路线”，不会把答案写进图中。
- 链环错答流程依次出现题型自查和结构诊断，未提前显示正确答案。
- 互动页和练习页无控制台错误。

## 7. 后续推广规则

其他三年级章节推广时应复用本样板的质量门槛：先确定课本主线，再为每个基础知识设计有明确联系的提升与思维挑战；题目要覆盖核心、迁移、挑战和独立复习；图形、交互状态、判分和讲解必须来自同一数学模型；自查和错因诊断必须随题型改变，不能使用通用口号。
