# 数学小侦探：把错题发给 ChatGPT

数学小侦探是短训练：判断模拟做法、找证据、改正，再换一种方法验证。现已增加GitHub自动收件；原课程、首答、积分、宠物和已有侦探记录保留。

## 以后怎样加错题

1. 在已连接并有GitHub写权限的ChatGPT对话里发错题照片、截图或文字，说：**“把这道错题加入数学小侦探，再出一道类似错案和一道正确案。”**
2. ChatGPT核对题目、复算，再把匿名训练包投递到 `lovestream/math-learning` 的 `detective-inbox` 数据分支。题目不清楚时先在聊天里补条件。**原作业照片、姓名和学校不提交公开GitHub。**
3. 程序先更新到支持该题型的PR提交，再双击 `start.command`（它只构建和启动当前目录代码，不会自动拉取或切换Git分支）。网站启动及每15分钟自动检查；进入侦探页时也会检查是否需要刷新。数学模板完整核验通过，直接加入**今日案卷或新收到的训练**（同一版本只展示一次），不用填表或逐题勾选发布。
4. Kevin点**立即调查**就能练，不必等明天。当天已有三案不被替换；新收到的题以后也会参与每日2错1对计划。

ChatGPT必须真实调用GitHub写入工具；没有权限或写入失败时不能说已投递。**“GitHub已投递”和“这台电脑已收到”不同**，本机结果以家长页为准。当前不会把本机学习记录或收件回执上传给ChatGPT。

## 怎么知道收到了

家长中心输入原有6～12位密码，打开**数学小侦探 · 案卷管理**，首页就是错题收件箱：

- **已收到，可立即练**：本机独立数学核验通过。
- **待家长核对**：题型暂不能可靠自动验证，或自动发布已暂停。点“打开待核对案卷”查看，未审定时不出现在儿童新案列表。
- **数学核验拒绝**：题干、模拟做法、答案、逆查、单位或图示与模板不一致，不发布错题。
- **同步暂不可用**：断网/限流/超时，保留旧训练并按提示自动重试。也可点“立即同步”。

目前可自动核验10种模板：原来的卡片、运算顺序、长度换算、等组、排序、绕线六类，以及平均质量、逆向称量、弹簧总长、弹簧逆向四类。其他复杂图形或开放解释可以投为待核对，不能因为ChatGPT说“有把握”就自动放行。

家长可关闭“数学核验通过后自动发布”；之后接收的包保留待核对。已发布、正在做和历史题保持不变。重复收到同包不会重复建题或发徽章。

## 示例与手工录题是备用

正常录题只需聊天发题。离线录题、检查待审题、撤回旧题时，展开**高级 / 备用方式**，原手工编辑、预览、三项发布核对仍在，旧稿不删除。

首次也可逐案预览后启用14宗匿名示例（10错4对）；第15宗铁丝题题意完整，缺原始计算过程，继续留作历史草稿；新投递的三宗绕线案明确使用匿名模拟步骤，不冒充原始作答。不要把这些示例说成孩子原作业完整过程。手工发布仍由家长核对三项；自动接收则明确记录为“本机数学核验”，不会冒充家长勾选。

## Kevin怎样调查

- **先判断**：有问题／没问题；首判封存，后来订正不覆盖。
- **找证据**：有问题时点第一处错行并选依据；没问题时只选核对依据，不圈不存在的错误。
- **写结果**：输入、选项或排列卡片。排序可拖动，也可用上移／下移按钮。
- **换方法验证**：完成另一条路线的检查，再看完整解释。

给过线索、判断或提交后需要订正，都如实记录为“订正／线索支持完成”。“本次未用提示完成”也包含条件图支架，**不等于撤去模型后的独立迁移或长期掌握**。

口述题停在“待家长核对”。家长在案卷管理底部查看首判、提交、线索和历史，听完后选 **解释与验证成立** 或 **需要再核对**。批阅可以更正，历史保留；孩子可以点“重新核对，保留原记录”再调查。给孩子的公开反馈可见，私有来源不要写进反馈框。

## 保存、冲突和备份

草稿约0.7秒自动保存。显示“记录已保存在本机”后可暂停；刷新后从调查记录续做。若连接中断，保留页面并点“重试保存”；未保存时系统会阻止站内离开。也可以下载本页草稿。不要在尚未保存时强制关闭浏览器。

另一标签已保存时会返回冲突提示，不覆盖新记录。先保留／下载本页输入，载入最新记录，核对后再提交。

完整进度备份包含侦探案卷、私有参考答案与来源，因此启用模块后，**导出、导入和恢复须先解锁家长工作台**。仍使用原来的家长中心备份按钮；不含侦探字段的旧备份继续兼容，导入前仍自动备份。密码不随学习进度导出。

## 奖励与本版范围

本版只给侦探勋章，不兑换积分。相同案卷版本不能反复领；每天最多三枚；待家长核对时不发，审核更正为回补会撤下该案勋章。

目前上限为200宗案卷、每案20个发布版本、1000次调查、400天计划、侦探存档3MiB；临近上限会停止新增并提示备份，不悄悄丢历史。不要把图片塞进题面或备份字段。

V2自主自查已增加1/3/7/14日新参数复测（与原课程1/3/7/21安排独立）。尚未实现：正式练习错题自动转案、网站OCR/原作业图片存储和本机收件回执上传。照片由聊天中的ChatGPT识别，不上传网站或公开仓库；复杂题仍需核对。

## V2：从找别人错误到自己检查

儿童页有两个入口：“观察别人的做法 · 找证据”和“自己解、自己查 · 延迟复测”。原来的四步探案保留；它不是四层能力的改名。

1. 看别人的做法：判断正确、错误；新对照例案还可选“过程不足，不能判断”。最后答案正确不代表推理有效，未知的原过程不编造。
2. 找第一处可证明的问题、选择依据与数学分类，再改正和反查。分类只描述数学行为，不推断孩子态度。
3. 在题族中可打开同类错例和正确对照，或选“换条件 / 求未知量”，独立解不同参数的反向题。
4. “自己解一题”先封存首答和可选思路；不会出现对错。填写第二次答案以及亲自算出的反查结果，选“完成”或“仍不确定”，一起封存后才给反馈。没有新增勾选打卡。

自主自查区能区分首答正确、反馈前自己改对、首答对却改错、自查未发现、辅助后完成、首答未评分。点提示、条件图或家长帮助会记时间。解释不靠关键字自动判对，由家长核对；数值符合也不等于长期掌握。

默认在首次学习后第1、3、7、14天提醒做一题；延迟复测不预填反查算式、不实时提示对错，也不使用已见参数。其他有效验证方法会保存供家长核对，自动核验只接受题型规定的反向关系。不确定可以如实记录，不因选了“检查完成”自动判正确。

家长在“自主自查、迁移证据和1/3/7/14日复测”中看首答、辅助、二答和检查过程，可暂停、恢复或顺延90天内的日期，批阅与更正只追加历史。标记辅助或回补后，该记录不再支持当前独立证据标签；原始数学快照仍保留。

8个题族每族最多240个不重复自主参数（另有16个保留审校参数）；用完明确提示回补，不循环熟题。自主命名空间最多1000次/2MiB，并受整个侦探库3MiB和互动库6MiB预算约束；上限处拒绝新增、原子回滚，要求导出备份，绝不静默删除。儿童列表保留最近100条及未完成记录，完整历史在家长页和备份中。自主训练和复测不发勋章或积分。

本机按Asia/Shanghai日期安排复测；同族每日最多推进一次。设备时间倒退超过5分钟、跳跃超过一年会阻止写入并请核对时间，原记录保留。
