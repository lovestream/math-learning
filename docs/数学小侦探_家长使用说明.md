# 数学小侦探：家长使用说明

数学小侦探是独立的短训练：判断一份模拟做法是否有问题，找证据，改正，再换一种办法验证。它不会把原课程标为掌握，也不改变积分和宠物成长规则。

## 第一次打开

1. 双击项目里的 `start.command`，在左侧点 **家长中心**。
2. 在原有家长工作台设置或输入6～12位数字密码。解锁后，下面会出现 **数学小侦探 · 案卷管理**。
3. 点击左侧案卷，核对原题、做法、参考解释和验证方法。点击 **预览儿童题面** 可以查看图示及模拟做法。示例为匿名改编，不是Kevin原作业逐字复原。
4. 回到 **批量审核**，核对三个发布选项，再点 **审核并启用14宗示例**。也可逐案审核发布。示例有10宗错误案、4宗正确案；铁丝题因缺完整原题保留草稿，不会跟着发布。
5. 点左侧 **数学小侦探**。每天出现三宗案，包含两宗错误案、一宗正确案，顺序会变化。已开始的调查可以在记录里续做。

未经您核对，示例不会自动冒充“家长已经审定”。至少要有两宗错误案和一宗正确案，才能生成每日混合计划。新发布的案卷参与下一次生成的计划；当天已有计划通常保持稳定，不挤掉已开始的调查。

## 随时加入真实错题

点 **手工新增案卷**，填写：

- 原题：条件、单位、要求完整，儿童角色用“小智”等虚构称呼。
- 模拟做法：每行一步。只知道一个错误答案，就只写那个答案，不替孩子编造思路。
- 正确结果、理由和另一种检查方法。
- 有错／没错、第一处可证明的错行、错误模式。没错的题不用指定错行。

默认允许孩子口述，最后由您听完解释后核对；不会用AI或关键词自动判对。对答案确定的题，可以在“儿童怎样改正、怎样验证”里选择精确数值、选项或排序，填写审定答案和固定单位。**数值输入只接收数，不接收长篇解释；多种解法的题优先用口述。**

验证问题要与原解法不同。例如原来是乘法求总数，验证可用除法分组；不能把“我检查过了”当作验证答案。

可在展开项中修改三层线索、依据选项、私有来源。手工题还可填写“条件图卡片”，每行一个数量条件，儿童题面会显示对应条件卡。原始来源与私有备注不发给儿童。发布时会额外替换Kevin／当前学习者名字及常见联系方式；仍请亲自核对其他姓名、校名等身份信息。

**保存草稿 → 预览 → 三项审核 → 发布当前案卷**。草稿不进儿童题库。已发布案卷保存修改后，儿童仍看到原发布版本；再次审核发布才生成新版本。撤回／归档不删除旧作答。

## Kevin怎样调查

- **先判断**：有问题／没问题；首判封存，后来订正不覆盖。
- **找证据**：有问题时点第一处错行并选依据；没问题时只选核对依据，不圈不存在的错误。
- **写结果**：输入、选项或排列卡片。排序可拖动，也可用上移／下移按钮。
- **换方法验证**：完成另一条路线的检查，再看完整解释。

给过线索、判断或提交后需要订正，都如实记录为“订正／线索支持完成”。“本次未用提示完成”也包含条件图支架，**不等于撤去模型后的独立迁移或长期掌握**。

口述题停在“待家长核对”。家长在案卷管理底部查看首判、提交、线索和历史，听完后选 **解释与验证成立** 或 **需要再核对**。批阅可以更正，历史保留；孩子可以点“重新核对，保留原记录”再调查。给孩子的公开反馈可见，私有来源不要写进反馈框。

## 保存、冲突和备份

草稿约0.7秒自动保存。显示“记录已保存在本机”后可暂停；刷新后从调查记录续做。若连接中断，保留页面并点“重试保存”；未保存时系统会阻止站内离开。也可以下载本页草稿。不要在尚未保存时强制关闭浏览器。

另一标签已保存时会返回冲突提示，不覆盖新记录。先保留／下载本页输入，载入最新记录，核对后再提交。

完整进度备份包含侦探案卷、私有参考答案与来源，因此启用模块后，**导出、导入和恢复须先解锁家长工作台**。仍使用原来的家长中心备份按钮；不含侦探字段的旧备份继续兼容，导入前仍自动备份。密码不随学习进度导出。

## 奖励与本版范围

本版只给侦探勋章，不兑换积分。相同案卷版本不能反复领；每天最多三枚；待家长核对时不发，审核更正为回补会撤下该案勋章。

首版上限为200宗案卷、每案20个发布版本、1000次调查、400天计划、侦探存档3MiB；临近上限会停止新增并提示备份，不悄悄丢历史。不要把图片塞进题面或备份字段。

尚未实现：正式错题自动转案、按易错模式的1/3/7/21新情境复习、OCR／作业图片、批量导入。以上不影响手工录题、混合三案和完整调查使用。请先试几宗，记录Kevin是否读懂、在哪里误判、能否解释验证，再决定下一阶段。
