# 数学小侦探：安全升级与回滚

`start.command` **只构建并启动当前文件夹里的代码，不执行 git pull、checkout 或切换分支**。GitHub有新JSON是“内容投递”；有新模板/界面源码是“程序升级”，两者不同。本说明不表示已重启家中电脑的服务。

## 本轮程序与内容

- 程序：PR #1 的 `audit-fixes-20261002`，使用通过CI的具体提交，不使用旧main替代。
- 内容：`detective-inbox` 数据分支。仅同步匿名JSON，不把这个分支合并进程序分支。
- V2程序兼容旧oracle.v1/v2案卷；新核验写oracle.v3，自主记录放在可选selfTraining命名空间。旧程序未必能读取v3记录，因此回滚需使用升级前备份，不能仅回退代码后继续写新存档。
- 新绕线包若先被旧程序收为待核对，新程序会重新验证旧oracle待审回执；不会覆盖本机编辑、发布、撤回或归档过的案卷。

## 正式升级前（需使用者确认后执行）

1. 在当前网站确认没有未保存草稿，记录当前程序的分支和完整SHA：在**实际启动目录**执行 `git branch --show-current`、`git rev-parse HEAD`、`git status --short`。有未提交改动先保存，不强制重置。
2. 家长解锁后导出完整学习备份，保存到不上传公开仓库的位置。学习JSON包含答案和私有来源；它**不包含家长密码配置**。
3. 批准暂停服务后，用原目录的 `stop.command` 停服，再复制完整 `data/` 到独立安全目录：包含SQLite、家长密码/恢复信息和backups。不要复制运行中SQLite主文件作为唯一备份，不删除任何WAL/SHM文件来“修复”。不得把这份副本提交GitHub。
4. 更新**程序目录**到已验收PR分支：先 `git fetch origin`，在工作区干净且已保存原SHA后使用 `git switch audit-fixes-20261002`、`git merge --ff-only origin/audit-fixes-20261002`。核对实际SHA等于交付报告/CI对应的SHA；如分支分叉或本地有改动，停止并保留现场，不用 `reset --hard`。
5. 双击这个目录里的 `start.command`。它先构建，成功后才替换后台服务。启动失败时保存日志，别重复导入或重置数据。
6. 家长用原PIN解锁，核对课程首答、已学位置、积分流水、宠物/背包、侦探历史。家长收件箱确认新包为“已收到，可立即练”；儿童页同一版本只在今日或新到一区显示。若有本机编辑冲突，按提示人工核对，不自动覆盖。

## 升级失败后的回滚（需使用者确认）

1. 保留错误日志和**升级后**导出；停服后另外完整复制升级后的data，避免升级后产生的新学习记录丢失。此副本用于后续恢复，不能直接拿给旧程序继续写。
2. 在保留现有目录的前提下，将程序恢复到事先记录的旧SHA。将升级前的完整data副本恢复到独立的旧版本运行目录，再构建/启动旧程序；不要将旧文件和新文件混装在同一data里，也不要仅覆盖SQLite而漏掉密码配置。
3. 核对原PIN、首答、积分、宠物、调查历史均与升级前一致。恢复学习JSON不会自动恢复PIN；完整停服目录副本才同时保留它。
4. 明确告知升级后新增的学习记录暂保存在新版副本，**不宣称已合并**。确认如何迁回后再清理副本。

## 可重复的隔离预演

先安装依赖并构建，再运行 `npm run test:detective:upgrade`。脚本只接受自己创建的OS临时目录，不提供真实data路径参数；从固定 `1d9c68197449e45dd273978f30fa3844bc4f562e` 程序生成模拟存档，包括课程首答/自查/辅助、积分与宠物、5包15案和旧版待审铁丝包。它实际启动旧、新、回滚服务并比较字段，检查原PIN、导入恢复、损坏备份拒绝、占用端口启动失败及完整旧备份回滚。

首次浅克隆需先取两份固定Git对象（仓库根目录执行）：

```sh
git fetch --no-tags --depth=1 origin 1d9c68197449e45dd273978f30fa3844bc4f562e
git fetch --no-tags --depth=1 origin c6e6eaedca53c0976af3ab6e187e2980e4e94430
npm run build
npm run test:detective:upgrade
```

结果在 `output/playwright/v2-audit/detective-upgrade.json`，截图及trace在同目录。五包数据来自固定Git blob，通过隔离fetch夹具重放，**不是在线GitHub网络验收，更不是Kevin真实电脑升级**。真实服务切换仍待使用者批准。

## V2完整回滚补充

再运行 `node scripts/verify-detective-v2-upgrade.mjs`。浅克隆先fetch固定基线 `a7c05aaa8d9c5eabae4f3453807f830da1cbf279`。此脚本只归档旧版server/shared/content到OS临时目录；建立12宗旧待审案、保存升级前checkpoint，新版重验发布、保存自主纠错并导出恢复；再用原checkpoint和旧程序验证完整回滚。旧程序会拒绝含selfTraining的新备份，不删除新字段。新增自主记录只留在新版备份，不能冒充已迁回旧库。此演练不访问正式data或NAS。
