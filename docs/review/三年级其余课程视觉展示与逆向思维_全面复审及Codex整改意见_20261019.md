## 3. P1-02：G3-U02-B03“同一组数字、两种单位关系”的场景切换错配

### 核查到的证据

- `content/pilot/mixed-operations.mjs`：
  - A：**12颗红珠＋8颗蓝珠**，两种都需要每4颗装一盒，`(12+8)÷4=5盒`；
  - B：**原有12袋珠子＋8颗散珠**，只把散珠再装袋，`12+8÷4=14袋`。
- `content/pilot/classrooms.mjs`：当前这课的固定`mission`为“先合并红蓝珠，再按每盒4颗分装”，`symbols`里也只写A算式。
- `src/studio/ChildClassroom.tsx` 第25行：第3步直接`{content.mission}`，然后才渲染可以切换A/B的`TeachingWidget`。
- 归档实际截图`docs/review/evidence-desktop-20261009/screens/desktop-G3-U02-B03-operated-1440.jpg`：场景B按钮选中，实验正文说“仓库原有12袋……”，页面顶端依然命令“先合并红蓝珠”；数学活动区域里还出现“A · 顺序与模型”标题，需要确认场景标题是否也没有同步。

### 建议最小修复

- 第3屏最上方用**不预先宣告某一固定故事答案**的总任务，例如“先判断哪些量能直接相加，再看是否要用括号”；或者由实验模型提供`activeScene.mission`动态渲染场景A/B各自的提问；保持第1屏原故事与第5屏“原故事算式”明确不随场景错变。
- 场景切换后，第3屏的**提示语、选中场景名、图中单位、算式、结果标签、讲解问题**必须与当前场景一致；不能出现场景B配场景A的头部、提示和`5盒`答案。
- 避免把A与B其实不同的“12颗/12袋”混为一谈；这应成为**专门测试用例**，选择A、选择B、返回A，并检查两者的单位、公式、任务文本及存档回放。
- 对其他有场景A/B、不同数量或不同单位的教具做一次**同类语义扫描**；生成逐场景`label → question → units → geometry → expression → explanation`一致性矩阵。**优先修有具体错配证据的课**，不需要重构70课。

验收例：场景B任何可见活动文案都不能再要求“合并12颗红珠＋8颗蓝珠”；切回A也不能留下“原有12袋”的算式与结果。首答、三勾与849正式题ID不改。

### 5.3 不足和下一步建议

**逆向“有”≠已经有系统性的逆向思维训练。** 当前专项11题只覆盖10个课程入口，部分分数/星期题偏解释或逆向检查，不是所有都为“已知结果求未知条件”的强逆向。现有其他课程也可能有逆算、验算、变量倒推，但本轮没有对849题再做全量语义重分类，**不能据此断言只有这11道逆向题**。

建议先建**小型“逆向思维专项路径”索引**，无需添加新的首页大模块或修改70课：
