# 第一课模板推广与三项自查（2026-10-09）

依据 Kevin 2026-10-08 的实际试课反馈，沿用“换一个位置，看到的样子为什么变了”的形式。本轮基线是 PR #1 `8e9115442b3978eee0d4821750ce04f47954bd26`，保留三年级课程与教具架构，未合并 main。

|---|---|---|---|

六步为：真实问题 → 先猜一猜 → 亲手实验 → 说出发现 → 写成数学 → 自己验证。六节静态课第三步准确标为“画图想一想”，说明使用纸笔与关系图，不提供虚假的拖动控件。每课猜想与任务单独编写；实验仍使用现有专用模型。发现先由孩子口头解释，需要时才展开关系；完整例子仍按需展开。数学表达页明确回到第一步的故事；实验中改过数字或条件时，提示孩子照同一方法另写新情况，不把固定故事的表达冒充当前变式的实时答案。所有步骤可自由选择，课堂位置、猜想及模型操作继续保存。

只改展示与自查形式：观察／质量五课的考核版本仍为 `2026-10-07.2`，其余为 `2026-10-02.1`；展示修订号为 `2026-10-09.1`。四至六年级、43张暂缓卡和已有思维卡考核未扩展。两处乘法故事改成更清楚的儿童语言，数量条件与答案未变。
