# Kevin三年级：全单元内容质量复查与改写记录

2026-09-25。目标是把“基础知识 → 关系或条件发生变化 → 数学思想”的要求用于全年，而不只补一个长度专题。四至六年级保持冻结。

## 本轮做了什么

逐课检查60课的现实任务、原因说明、P05–P08，以及全部60张思维卡。48课各替换1道偏浅或重复的备选练习，另12课保留已有合格对照、反例或边界题。题总数不增长：仍60课720道课内/回顾任务，另60张思维卡与6道专用检查，共786个任务。11幅新课内图加此前15幅思维图，共26幅。

没有把所有基础题改成奥数题：每课基本目标与最低过关题不变，48道新题都在可选位置。基础、提升、独立迁移是不同证据。720道原题不宣称本轮从零重新语义证明；保留原审核记录，并重审本次改写与关联关系。

**现在：**小乐算612÷6，把商十位的0漏掉，写成12。请不重做整套竖式，先用乘法检查这个答案，再说明0记录了什么。

**参考：**12×6=72，与612不符；正确为102，0表示每份没有整十。

**增加的思考：**用逆运算定位位值错误，理解0不是可有可无的空白。

### G3-L02-B05-P08

**原来：**96颗球，每袋4颗，每盒装3袋，共能装几盒？

**现在：**96支笔要装盒。方案甲：每小袋4支，每盒3袋。方案乙：每小袋3支，每盒4袋。两种方案各装几盒？每种用的小袋数相同吗？请区分一盒支数、袋数和总盒数。

**参考：**两种都装8盒；甲24袋，乙32袋。

**增加的思考：**多层分组中区分相同的总量与不同的中间数量。

### G3-L02-B06-P08

**原来：**同样120张纸，原来每组分6张，改为每组分8张，可分几组？

**现在：**同样120张纸全部平均分。方案甲：每组6张，需要几组？方案乙：分给6组，每组几张？两题都写120÷6，为什么答案的数字一样，却不是同一个问题？请分别说6和商20代表什么。

**参考：**甲20组，6表示每组张数；乙每组20张，6表示组数。

**增加的思考：**把平均分与包含分的不同含义说清，不能只看算式认题型。

### G3-L03-B01-P06

**原来：**“所有长方形都是正方形”正确吗？

**现在：**用4根同样长的吸管首尾连成四边形，接头可活动。它一定是正方形吗？把它轻轻推斜后，哪些条件仍满足、哪个条件可能不满足？怎样才能确定它是正方形？

**参考：**不一定；边仍全等，角未必为直角。还要检查四个角都是直角。

**增加的思考：**按充分条件分类，用可操作反例检验“等边就够了”。

### G3-L03-B02-P08

**原来：**用一根28厘米长的铁丝围成正方形，边长多少？不计接头。

**现在：**一块长8米、宽5米的长方形菜地，有完整的一边紧贴墙，贴墙一边不用围栏，另三边都围。选8米边靠墙和选5米边靠墙，分别需多少米围栏？哪种更省？

**参考：**8米边靠墙需18米，5米边靠墙需21米；长边靠墙省3米。

**增加的思考：**现实约束决定哪些边属于所求量，并比较两种方案。

### G3-L03-E01-P08

**原来：**把4个单位正方形排成2行2列和排成一条直线，周长一样吗？

**现在：**两个边长3厘米的正方形纸片不重叠地拼在一起。一种让完整的一条边贴合，另一种只让两个角碰到。分别沿拼后露在外面的所有边走一遍，总边长各多少？为什么第二种不能也减去两条3厘米边？

**参考：**整边贴合为18厘米；只碰角时两片外露边长合计24厘米。

**增加的思考：**从接触点与公共边区别解释周长变化的边界。

### G3-L04-B01-P08

**原来：**两个纸片分别数出12格和15格，但方格大小不同，能直接判断谁面积大吗？

**现在：**两张纸都用同一种1平方厘米小方格测量。甲正好覆盖12整格；乙覆盖8整格，另有8个恰好半格的部分，这些半格不重叠。能因乙只有8整格就说它面积小吗？请把半格成对拼起来比较。

**参考：**不能；两张面积相等，都是12平方厘米。

**增加的思考：**把零碎部分等积拼补，面积是覆盖量而非整格计数。

### G3-L04-B02-P08

**原来：**长方形面积42平方厘米，长7厘米，宽多少？

**现在：**长方形纸原来长6厘米、宽4厘米。现把长增加2厘米、宽减少1厘米。面积一定变大吗？先画两张方格图再比较；如果改为只增加长、宽不变，又会怎样？

**参考：**同时改变后仍24平方厘米；只增长则变为32平方厘米。

**增加的思考：**两个变量同时变化时用模型比较，避免单因素直觉。

### G3-L04-B03-P08

**原来：**面积都是12平方厘米的2×6长方形与3×4长方形，周长各是多少？

**现在：**一张8厘米长、5厘米宽的长方形纸，从角上剪去一块3厘米长、2厘米宽的小长方形，小块两条边沿原纸两条边。剩下面积多少，周长与原来相比怎样？请分别标出消失的边与新露出的边。

**参考：**面积34平方厘米；周长仍26厘米。

**增加的思考：**同一剪切同时追踪面积与边界，避免混同两种量。

### G3-L05-B01-P06

**原来：**只调查喜欢篮球的同学，能据此推断全班最喜欢什么运动吗？

**现在：**全班20人每人选一种最喜欢的游戏。只采访了8人，其中5人选跳绳、3人选踢毽子。现在能断定跳绳在全班最多吗？请给余下12人安排一种可能的选择，让结论变成踢毽子更多。

**参考：**不能；例如余下12人全选踢毽子，全班就为跳绳5、踢毽子15。

**增加的思考：**用未观测数据构造反例，而不是只回答样本不够。

### G3-L05-B02-P06

**原来：**“本次8人中10–19分钟的人最多”，能写成“全校学生都读10–19分钟”吗？

**现在：**老师只保存了分组表：阅读不足10分钟的2人，10到19分钟的3人，20分钟及以上的1人。小乐说全班阅读总时长一定是80分钟。能确定吗？请列两组都符合这张表的6个整数时长，但总时长不同。

**参考：**不能。例如5、5、10、10、10、20合计60；9、9、19、19、19、25合计100。其他符合分组且总和不同的两组也可。

**增加的思考：**识别统计汇总丢失的信息，构造同表不同数据。

### G3-LP01-B01-P08

**原来：**2028年2月有几天？全年有几天？

**现在：**2028年是闰年，2027年是平年。两年都从2月28日上午9时开始，经过整整3天，各是几月几日上午9时？请一天一天跨日期，不要把起始日期算作已经经过1天。

**参考：**2028年为3月2日；2027年为3月3日，均上午9时。

**增加的思考：**用日期间隔处理不同月长，区分日期与经过天数。

### G3-LP01-B02-P06

**原来：**上午10时开始，持续2小时30分，几点结束？

**现在：**13:40从家出发，走25分钟到公交站。车在14:00和14:20发车，错过就等下一班，坐车15分钟到图书馆。最早几点到图书馆，中间等车多久？请把走路、等车、乘车分成三段。

**参考：**14:35到；等车15分钟。

### G3-LP01-E01-P08

**原来：**本月1日星期五，8日和10日分别星期几？

**现在：**某月有30天，1日是星期一。这个月星期一和星期二各出现几次，其他星期各几次？下个月1日是星期几？请把整月拆成完整的周和剩下的天。

**参考：**星期一、二各5次，其余各4次；下月1日星期三。

**增加的思考：**周期里的整组、余项与下一位置要分别判断。

### G3-L06-B01-P08

**原来：**2元5分写成多少元？为什么不是2.5元？

**现在：**两张价格标签分别写2.5元和2.05元。店员擦掉小数点后都想按整数理解。原来这两种价格各是几元几角几分，相差多少分？请用钱币说明0的位置。

**参考：**2.5元是2元5角，2.05元是2元0角5分；相差45分。

**增加的思考：**把小数位值还原为具体单位，解释占位0的作用。

### G3-L06-B02-P08

**原来：**3.05元和3.5元哪个金额大？

**现在：**用数字0、4、5各一次，在固定格式□.□□中填数，小数点位置不能移动。要使结果小于1且尽可能大，该怎样填？把其他符合小于1的填法也写出，再比较。

**参考：**最大0.54；另一个是0.45。

**增加的思考：**在位置与范围限制下有序枚举并优化。

### G3-L06-B03-P08

**原来：**一条绳长5米，剪去1.7米，还剩多少米？

**现在：**买两件物品，标签为3.6元和2.8元。店员把第二件的小数点看错，记成28元。总价会比正确的多多少元？不先重算两个总价，能否只比较哪一项改变了？

**参考：**多25.2元。

**增加的思考：**把误读位值与和的变化连接，消去不变部分。

### G3-L07-R01-P06

**原来：**全班“最喜欢剪纸”票数最多，就能确定每个人都喜欢剪纸吗？

**现在：**20人做手工，每人需3张纸。甲店每包10张4元；乙店每包8张3元，两店都只卖整包。只在一家买，选哪家花钱少？还剩多少张？请同时考虑包数取整、价格和余纸。

**参考：**两家都是24元；甲买6包正好60张不剩，乙买8包64张剩4张。只按费用无法区分更省。

**增加的思考：**多约束方案比较，排除单看包装价的直觉。

### G3-L07-B01-P08

**原来：**班级20人，喜欢足球12人、篮球11人，每人至少喜欢一项，两项都喜欢的有几人？

**现在：**画画组8人、唱歌组7人，全部来自一个20人的班。没有说两组是否有共同成员。至少参加一组的人，最多和最少各多少？两项都没参加的人，最少和最多各多少？请画出两种极端名单关系。

**参考：**至少一组最多15、最少8；都没参加最少5、最多12。

**增加的思考：**用包含与分离构造上下界，证明不只一个可能答案。

## 后续实现的统一规则

1. 进入课本章节先显示基础任务，过关后可选本课延伸或同方法卡。不得再次创建重复课程或重复奖励。
2. 改变条件时明确告诉Kevin改了哪一点：位置、整体、份数、允许操作、信息充分性或问题目标。不能只悄悄换数字。
3. 题目需要的图默认可见；提示性的图默认收起。例如共线点的两种位置是要孩子构造的，不能一开始就把两种答案模型亮出来。
4. 解释可以画、摆、说或列式；不能只做“能/不能”的选择就判掌握，更不能只用参考文字逐字匹配。
5. 每天最多一道提升/奥数，复杂任务可跨日。原有分日复习针对原目标；提升需单独记录是否独立、用过哪级提示、能否迁移，证据不足就标待迁移。
6. 先实现并试学代表模型，再推广渲染器；图文审阅文件可离线读，但不代表网站已接入或互动已验收。
