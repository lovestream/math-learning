## 复跑与审校失效机制

```sh
node scripts/build-final-task-review.mjs --check
python3 scripts/verify-final-task-relations.py
node scripts/audit-formal-tasks.mjs --write
node scripts/build-semantic-ledger.mjs --check
npm test
npm run build
npm run content:check
node scripts/run-browser-ci.mjs --only=verify-final-tasks-browser,verify-template-browser,verify-save-stress-browser,verify-evidence-browser
```

正式审计不再把solution-equation提升为numericProofVerified。分别输出schemaChecked、solutionInternallyConsistent、independentlyDerivedFromPromptOrDiagram、agentSemanticReviewed、humanTeachingApproved。题干、解答、提示、答案或contentVersion改变时，旧代理证据失效，封存清单生成器拒绝直接覆盖；必须重新核对具体题后更新该记录。
