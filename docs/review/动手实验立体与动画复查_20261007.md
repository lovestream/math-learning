# 动手实验：立体呈现与动画复查

针对“六面纸盒折起来仍像平面，而猜物体的立体呈现很好”的反馈，本轮在原项目内重做纸盒的显示与播放，并检查全部70个课程入口中的29个现有可操作实验。课程知识、课题ID、题目、积分和掌握规则没有变更。

## 六面纸盒的具体修正

- 闭合后不再沿用展开图的固定小比例。按当前三维顶点取景，整个折叠与旋转过程保持完整入镜；闭合盒子占据主画面的中央。
- 与观察物体、隐藏积木使用同一个立体渲染组件。面有与方向相关的明暗、材质渐变、轮廓、内缘与落地阴影；编号投影在真实纸面上，并保持可辨读。
- “完全展开／折到一半／折成盒子”播放连续铰链折叠，新增播放与暂停；滑条仍可直接操作，鼠标与方向键仍可旋转。
- 折叠按钮会回到斜向立体视角。从旧的正面平面视角拖动折叠滑条，也会恢复立体观察；仍保留正面、右面、上面作为有明确意义的正投影视角。
- 下方保留同一展开图的小编号地图，便于把折好的面与原来纸上的位置对应。
- 仍为原有的一种六面展开图，未把其他纸模板冒充同一动态模型。六面、铰链、相邻／相对关系全部沿用已验证的数学模型。

## 其他实验的改进与复查

| 实验类别 | 检查与改进 |
| --- | --- |
| 观察物体、隐藏积木 | 共用放大取景与方向光照；保留真实视角拖动、三方向正投影及隐藏积木反例。 |
| 天平、曹冲称象 | 横梁、吊线、托盘同步连续移动；装载／取走物体时船身连续下沉／浮起，静水面固定。物品拖动时跟随实际图形，放置有短暂落定反馈。 |
| 六节混合运算课 | 数字牌画面改成与具名数量对应的乘客、书、铅笔盒、珠子、整袋与钱袋。所有故事场景都从第一步跑到完成。净支出先形成一包，再扣钱，不把第一步画成已经付完的余额。 |
| 六节提升／思维实验 | 钱袋退款、每组的人和卡片、完整盒子替换、倒推路线都有明确图形。点阵分界线可直接拖；换计数方向是整块点阵旋转，颜色分块随同转动。 |
| 五节测量实验 | 保留链环实物拖入与接头放大、木板搭接、移动尺子、分段路线和点／间隔操作，逐项实际操作回归。 |
| 七节基础实验 | 苹果放入／新添、贴纸送出、彩带选取、地垫计数、拆盒与等量比较的反馈分别检查；补充对象入场、送出、选取与计数动画。 |

二维数学对象仍按适合测量与比较的平面视角展示，例如尺子、彩带、面积格子；没有为了“看起来立体”歪曲长度、分数或面积。质量实验的倾角和吃水仍是教学反馈，没有改成真实物理测量公式。

## 状态与动画分开

动画只连接两个真实模型状态，不写入每帧记录，不发探索积分，也不改变独立掌握证据。每次按钮操作仍只保存目标状态，支持旧备份、撤销和刷新恢复。减少动态效果偏好下直接显示目标状态；动画退出时取消帧任务，终点精确落到目标值，避免折到100%后仍无法核对。

点阵使用刚性旋转，不能直接插值交换横纵坐标：后者会在中途把所有珠子挤到一条对角线上。本轮新增验证覆盖每个旋转阶段的间距与面积不变。

## 验证与证据

数学与工程自动测试共87项；新增检查遍历展开／半折／闭合和多种视角，确认六面身份、有限光照、排序和取景边界，验证闭合对象足够大，以及点阵旋转不坍缩。87项测试、TypeScript、正式构建、内容检查和diff检查全部通过。正式构建浏览器检查全部通过，随后单独复查直接点击纸面选编号；重复测试等待恢复动作完成再检查下一次动画。

浏览器验收使用独立临时数据目录：

```bash
node server/index.mjs --port=4195 --data-dir=/tmp/kevin-motion-test
npm run test:browser -- --url http://127.0.0.1:4195
```

四个可复现脚本：

- `verify-hands-on-browser.js`：五课真实拖动、投影、折叠、称重、反例、保存、撤销和刷新恢复。
- `verify-classroom-flow.js`：错误首答→专用自查→订正→完成三题→次日复习。
- `verify-motion-browser.js`：连续折叠、暂停、旋转、旧平面视角恢复、减少动态效果、天平联动、船身移动、点阵拖线与旋转。
- `verify-lab-inventory.js`：全部70个入口；29处可操作实验分别操作并检查1440与390宽度，混合运算的所有故事场景计算到底，41张静态卡逐一检查入口标记。

结果和代表截图见 `evidence-motion-20261007/`。所有浏览器测试只写独立测试数据，不指向Kevin日常学习数据库。

## 不能混淆的完成边界

本轮复查的是已经存在的29个可操作实验。其余41课仍是文字关系卡，入口已明确改为“画图想一想”，未宣称已经有动画。它们需要按教学内容逐课制作专用实验，不能靠通用动画模板补数。Kevin真实试学仍需家长观察；截图和自动化通过不等于已经理解。
