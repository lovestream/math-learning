## G3-U01-B01 换一个位置，看到的样子为什么变了

内容版本：2026-10-07.2。教材单元：观察物体，印刷页1–5。建议先修：能辨认长方体、正方体、球、圆柱；不要求画三视图。

学习目标：能说清观察位置与所见面的对应。

### 第1屏：真实问题

Kevin给朋友寄一个玩具盒。盒子前面是红圆点，右面是蓝菱形，上面是黄星星。朋友只收到一张照片，能知道你站在哪边拍的吗？

对应图形：桌上这个盒子与拍照位置。盒子不动。先认清三个标记，再看相机站在哪里。

### 第2屏：预测

盒子放着不动，相机从正前方移到右侧，照片会怎样？

预测图形：相机从前方移到右侧：新照片先不揭晓。盒子不动。先认清三个标记，再看相机站在哪里。

- 仍然正对红圆点
- 改为正对蓝菱形
- 盒子必须先转一下

可以点选、口头想过后进入；一句话输入可选，预测不会直接判分。图形展示已知条件，不展示待猜的新照片、折好后的面关系、净重或替换质量。

### 第3屏：操作与证据

盒子固定在桌上，前面贴红圆点、右面贴蓝菱形、上面贴黄星星。移动观察者，不转动物体；用正面、右面、上面照片比较。

具体任务：拍三张不同方向的照片，指出观察者在哪里。

模型：spatial / observe / spatial.v2。必须呈现的证据：object、observer、direction、projection。

允许试错、撤销、重来；状态、参数和动作快照随课程保存。操作表示探索，不发答对积分、不直接记掌握。

### 第4屏：自己复述与发现

指着你的三张照片讲：盒子哪里没动？为什么看到的标记变了？

先自己讲，再按需展开参考关系：

- 固定的是盒子，移动的是观察者。
- 正前方、右侧、上方拍到不同的面；斜着看时，可以同时看见多个面。
- 同一件物体可以有不同照片。照片中的一个面，不能替代整个物体。

### 第5屏：翻译成数学语言

- 正前方 → 红圆点所在面
- 右侧 → 蓝菱形所在面
- 上方 → 黄星星所在面

另一个完整例子：

盒子前面有红点，右面有蓝点。Kevin只想拍到蓝点所在面的正面，应从哪里拍？

- 先找蓝点在哪个面。；先找蓝点在哪个面。
- 让镜头正对右面，而不是转动盒子。；让镜头正对右面，而不是转动盒子。
- 结论：从盒子的右侧正对蓝点拍。；把答案放回真实问题，检查单位、条件和结果是否对应。

## G3-U01-B02 看见一个面，能猜出整个物体吗

模型：spatial / hidden / spatial.v2。必须呈现的证据：object、observer、direction、projection、hidden-cubes。

允许试错、撤销、重来；状态、参数和动作快照随课程保存。操作表示探索，不发答对积分、不直接记掌握。

### 第4屏：自己复述与发现

正面都是2格时，为什么不能直接说总共2块？哪张新照片能帮助你？

先自己讲，再按需展开参考关系：

- 正面只记录能看见的轮廓。前排2块，可以挡住后排1块或2块。
- 后排有1块和2块时，正面都是2格，上面也都是2格；右侧能看到不同的后排高度。
- 同一张正面照片可以对应不同的积木总数。需要补充新方向的证据。

- 前排2块＋后排1块＝3块
- 前排2块＋后排2块＝4块
- 正面相同 ≠ 总数相同
