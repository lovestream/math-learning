## 一、事实依据与纠正

### 居民身份证号码（18位）

按国家标准GB 11643-1999相关行政机关解释：

| 位置 | 字段 | 三年级教学重点 |
|---|---|---|
| 1—2 | 省级行政区划代码 | 省、自治区、直辖市等 |
| 3—4 | 中间行政层级代码 | 多数情况下可帮助表示地市、地区等；**直辖市等有特殊结构，不能一律叫城市** |
| 5—6 | 县区级行政代码 | 县、区、县级市等；合前4位构成6位地址码 |
| 7—10 | 出生年份 | 4位，如2015 |
| 11—12 | 出生月份 | 2位，如05 |
| 13—14 | 出生日期 | 2位，如16 |
| 15—17 | 顺序码 | 区分同区域同生日人员；第17位奇数对应男、偶数对应女 |
| 18 | 校验码 | 由前17位按规则计算，结果10写X，只占一位 |

- **编码规则表示的是按编码规则采用的户籍行政区划，不意味着当前住址或出生地。**
- **性别标记在第17位（倒数第二位），不是校验码第18位。**
- **X不是随意填的：只有校验结果为10时才用X占1位**；三年级理解“查错位”原理即可，完整加权求余公式属于扩展，不作必答。
- 校验码通过，只能说明满足该算法，并不证明身份证持有人真实或所有信息正确。
- 页面仅显示拆分教学片段 `44 01 06｜2015 05 16｜003｜？`，问号为未提供的校验码；**不让孩子输入真实身份证号码，不采集真实姓名、户籍、生日、号码。**

权威依据：
1. 北京市公安局《公民身份号码的组成》：https://gaj.beijing.gov.cn/hudong/rddf/202003/t20200331_1771804.html
2. 上海市民政局《身份证号码的前六位数字是什么意思》：https://mzj.sh.gov.cn/2023bsmz/20230219/277963d83d3f4c5e.html
3. 平凉市审计局《浅析身份证号码校验在大数据审计中的应用》：https://sjj.pingliang.gov.cn/sjzc/ywjl/art/2023/art_e975e765957c44ac9e934637119a1ffd.html

### 邮政编码（6位）

传统四级六码：前2位省级邮政区域，第3位邮区，第4位县市/投递层级，最后2位投递局所。**这里是邮政分拣投递体系，与身份证6位行政区划代码绝不是同一套映射规则。**邮编可能对应多个收件人，需要完整地址；具体邮编以国家邮政局官方服务查询。

- 国家邮政局官方说明：https://www.spb.gov.cn/gjyzj/c200041/202510/745c2008e015403eb27fd9726f6bea07.shtml
- 官方邮编查询：https://zwfw.spb.gov.cn/flagship/yzbm
- 新华网关于“四级六码”的报道：https://www.xinhuanet.com/politics/2019-08/08/c_1124850664.htm

### 学校自编号 vs 国家正式学籍号

- 本课模拟的`03-02-07`可以解释为“3年级2班7号”，但跨班要加班号，升年级可能变号。
- 如要长时间跟踪在校同一学生，可设计`2024-0007`（入学年度＋同年唯一流水号）；要解决当年内不重号、不同入学年份不冲突；具体编码是模拟的、非官方强制规则。
- **全国正式学籍号由国家学籍系统按规则自动生成和分配，一人一号、终身不变。不得声称课堂里设计的号码就是正式学籍号。**
- 教育部《中小学生学籍管理办法》（2025）：https://www.moe.gov.cn/srcsite/A06/jcys_jyzb/202502/t20250207_1177647.html

## 二、教学目标：不只是背位数

| 层级 | Kevin能做什么 | 验证方式 |
|---|---|---|
| 理解1 | 判断一个数字在某规则里是数量还是身份/位置/编码 | 可举编码不能相加的反例 |
| 理解2 | 独立按6+8+3+1拆身份证，并再按2+2+2、4+2+2解释 | 在不展示完整真实号码的示意上标位置 |
| 理解3 | 准确认出第17位奇偶和第18位X规则 | 独立分辨003/004、X可能出现的条件 |
| 理解4 | 认识邮政6位层次，明确其与身份证6位地址码不同 | 解释同一邮编可有多个住户 |
| 应用5 | 按年级、班级和序号设计固定长度编码；检查补零和跨班撞号 | 自己举两个人的编号反例 |
| 迁移6 | 设计长效校内编号，解决升年级/换班的稳定性 | 比较03-02-07与2024-0007 |
| 反思7 | 判断校验码对错误检测的局限性、个人隐私边界 | 能解释校验通过不等于身份真实 |
