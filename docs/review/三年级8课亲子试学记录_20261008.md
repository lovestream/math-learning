# 三年级8课亲子试学记录

这是未填写的记录表，不是Kevin的掌握证明。建议每次1课，半小时左右：1分钟读题、10–15分钟探索、5–10分钟撤教具小测、2分钟解释。错了可以停下来回补，不要求凑齐进度。

## 每课如何观察

1. 让Kevin自己读题，不先解释答案。1分钟后请他说“现在有哪些东西？要找什么？”记录原话。
2. 操作时允许试错；第一次错在什么地方？反馈后能否自己解释为什么？
3. 收起教具，不给“全部符合”反馈。留下首答，自己检查，再作最终解释；老师/家长的口头提示也记录。
4. 24小时后从未见过的情境再做，不先看昨天的答案。家长核对条件、推理、自查和支架，不以点击完成代替掌握。

## 八节代表课与观察重点

|ID|内容|重点观察|撤去教具后|
|---|---|---|---|
|G3-U02-B03|括号与混合运算|是否把故事中的剩余整体放进括号，而非背口诀|用既有正式迁移组，逐步写第一步与中间结果|
|G3-U04-B03|连续进位|能否说清每次进位来自哪一列，换位值后总量不变|进入五题小测；保留原任务ID|
|G3-U04-B04|含0乘法|是否区分“这个数位没有单位”和“删除数位”|进入五题小测，重点看错误分析解释|
|G3-L02-B03|有余数除法|能否判断余数必须小于除数，剩下是否需再占一个容器|进入五题小测；正确数值还需解释现实含义|
|G3-U06-B03|同分母加减|是否知道小份大小未变，不能把分母也相加|进入五题小测；不同整体题交家长核对|
|G3-U01-B02|隐藏积木和视角|最高高度与块数是否混淆，单一照片信息够不够|纸笔分析新搭法；不要显示自动匹配|
|G3-UP01-B02|称象、水线、替换|替换时保持哪些条件，容器重量为什么不重复加入|用正式迁移组说明等量替换，口头解释留原话|
|G3-UP01-TH1|天平消元迁移|两边拿走的是否等量，能否用原条件验回|家长批阅探索后，到期进入无实时模型的新情境|
