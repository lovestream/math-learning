## 这次检查后的判断

之前34张思维题已有枚举、逆推、替换、不变量等方法，但长度单元主要还是无刻度尺与间隔计数，没有覆盖“看连接结构决定实际总长”；部分方法只出现一次，缺少条件改变后的对照。本轮补的是这些缺口，而不是单纯增加计算量。

现为60张可选思维卡：原有34张 + 20张参考暑假方法的改写/变式卡 + 6张长度连接卡；配15幅本地SVG与6条方法联系。全年60个课节点与720道课内/回顾题不变；连同5道诊断、1道独立迁移，三年级共786个独立任务ID。不是要求Kevin做完786题才可升级。

## 长度：由基础自然引出六种不同思考

| 题卡 | 要增加的思考 | 结果与必要条件 |
|---|---|---|
| G3-U03-TH3 | 两块搭接，找出重复计的段 | 30与25重叠8，覆盖47厘米；材料共55厘米是另一种量 |
| G3-U03-TH4 | 数接头，并分别处理不同重叠 | 4块各20，三处3、5、2，覆盖70厘米；没有三重重叠 |
| G3-U03-TH5 | 从拼好总长反求每处重叠 | 3块各30，拼成78；两处相等，各6厘米 |
| G3-U03-TH6 | 读链环结构，区分厚度与接头 | 外长40毫米；图定每接头由两个5毫米端部组成；4环3接头，130毫米 |
| G3-U03-TH7 | 判断信息不足，构造两种答案 | 两根20厘米、未知重叠，不能定总长；可举38与35厘米 |
| G3-U03-TH8 | 检验简单去重方法的边界 | 覆盖0–30、10–40、20–50；三对重叠全减会漏掉中间10，应为50厘米 |

学习顺序建议先TH3，再按理解选TH4/TH5；TH6先读单个接头放大图。TH7用于检查是否懂条件；TH8是困难选学，可留到以后，不能让它成为长度基础门槛。

**链环不能只凭“长4厘米、厚5毫米”猜公式。** 4厘米是外长还是内孔长、是否拉紧、接头怎样互扣，都会影响模型。本轮新图把条件写完整，所得13厘米只属于这张原创模型题。用户描述的原配图未在这份暑假PDF中出现，因此不宣称复原了原题。

## 对原有34张卡的处理

保留能要求解释、列全、给反例或证明的题：8球两次称量、有余数的多个解、分数整体改变、固定周长枚举、方格棋盘无法铺满等，不为了“新”而替换合格题。原有棋盘、周长缺口、对角分割、网格正方形、角、最短路径六题补配图；长度原两题仍作为别的测量思路，而不冒充已经覆盖连接与重叠。

按教材完成基础，再自由选相关卡。章内入口与奥数方法入口引用同一个ID、同一份帮助/掌握记录，不复制分数。同方法的近似题不连续堆给Kevin；先看一次独立解释，再选择改变条件的对照或隔日迁移。会算尚不能说明会解释，反过来有好的图或语言推理也不要求先会字母方程。
