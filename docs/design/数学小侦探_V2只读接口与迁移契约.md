# V2只读契约（统一学习家园未来迁移参考，本轮不跨站部署）

唯一实现源是math-learning PR #1。所有接口同源、本机127.0.0.1；不能直接暴露到公网或NAS。

## 公开只读

`GET /api/detective/today`：旧四步案的题面按phase白名单释放；不含家长备注、完整答案库和收件来源。

`GET /api/detective/self`：engineVersion=detective-self.v1，timeZone=Asia/Shanghai。返回8个题族、到期/暂停状态、带分子分母的统计、最近100条及未完成自主记录。first阶段只有题面/单位/未知角色；check阶段练习可取得反查操作说明，review模式不返回预填关系；两次提交固定后才返回result、answer、explanation。统计不包含未完成首答的正确性，不能据此提前探知对错。

稳定键：errorFamilyId、questionVariantId（engine+family+index）、attemptId、sourceKind、unknownRole。此命名空间没有课程任务ID或积分权益，不将新训练重复记入849题课程成绩。

## 家长只读与本地管理

`GET /api/parent/detective/self` 需要已有PIN会话；可读全部自主历史、firstAnswer/firstReasoning、selfCheckActions、preFeedbackRevision、hintExposure、feedbackReleasedAt、原始私有证据与批阅史。批阅评语是儿童可见的教育反馈，不放私人来源。原生家长Cookie仍仅用于/api/parent。

`POST /api/detective/self`：start/draft/first/final/hint/visual/parent-help，eventId幂等、expectedRevision冲突409。firstAnswer不可覆盖，final原子固定二答/检查再反馈。`POST /api/detective/examples`只启用审定的匿名过程/题族对照，不能上传自定义答案或任意HTML。

`POST /api/parent/detective/self`：schedule（revision、paused、dueDay）、review（revision、verdict、comment），均需eventId和PIN。批阅更正追加，不改原始快照；辅助/回补结论影响当前证据资格。两类写入受现有同源保护，无公开调时或测试接口。

## 版本、容量和回滚

旧detective schemaVersion=1不变；可选selfTraining.schemaVersion=1为显式新命名空间，含engineVersion、固定时区、seen、attempts、schedules。旧库不访问新功能时不自动生成自主记录。导入校验当前题目版本、首答指纹、答案数学、检查动作、统计快照和唯一variant，不用新解释回填旧作答。

文字/模型实质改动应发布新的engineVersion并保留旧解码器；当前程序明确拒绝未知未来版本，而非静默丢弃。导出格式仍为完整kevin-math-lab envelope.v1，由checksum和家长接口保护。回滚必须恢复升级前完整checkpoint，新版自主记录单独存档；旧程序不能读取新命名空间。

自主记录限1000次/2MiB，整侦探库仍为3MiB，互动库仍为6MiB。每族240个未见参数，用完停止；不偷偷循环、不删除证据。容量或磁盘异常整次写入回滚，原题保留在GitHub/备份，未来长库归档迁移另作决策。

当前不实施统一站功能、跨站认证、远程账户、英语、积分、宠物或正式服务切换。
