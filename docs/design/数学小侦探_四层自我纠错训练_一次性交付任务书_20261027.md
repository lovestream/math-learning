## B. 核心教育逻辑：四个“层级”，而不是把既有四步换个名字

**贯穿原则**：数学训练目标是“独立发现并修正自己错误的可迁移能力”，不是在别人故意写错的题里猜红叉；保留正误混合、真实性和逆向思维。阶段对应能力，允许学生按掌握证据推进，不能因做过一题就判长期掌握。

### L1 看懂并判断别人的做法（现有四步升级）
- 查看匿名模拟答案，先**判断正确 / 有错误 / 证据不足（仅在确实缺步骤无法唯一判断时）**，说明凭什么判断。错误案、正确案、**答案恰好正确但理由不充分/步骤不成立**的案应可表示为不同事实类型；不能把“答案对”误判为“推理正确”，不能假设所有案都有错。
- 保留原四步 judge→evidence→repair→verify、首判冻结和提示披露；证据选择要与真实数学条件对应。旧版 judge 二值协议/历史记录保持兼容；必要时只为新版本扩充三态和“过程充分性”字段，不破坏原有case。
- 既有日常建议3宗、约2错1对可继续作为普通模式，但不把固定比例显示给儿童，也不能利用固定比例构成猜题线索。

### L2 准确定位错误及原因（从结果判断升级到过程诊断）
- 找**第一处可以证明的错误**，区分“错误前仍正确的步骤”和“后面被带错的步骤”；也允许“结果正确、但推理无效/缺必要条件”与“不能从现有证据断言错误位置”。
- 学科内分类最少涵盖：①读题/所问对象或方向，②单位和数量感，③运算顺序/计算执行，④数量关系或模型（整体/部分、原长/增加量、平均/总量），⑤表达不完整/缺必要步骤，⑥验证未有效执行。只标注**观察到的数学行为**，不能臆测孩子说谎、注意缺陷或态度问题。记录原始步骤证据和分类理由。
- 支持“更正错行 → 写清改后结果 → 用独立关系反查”，以及判断“正确无须强行改”的分支。真实旧错题若只有最终答案，就标“原中间过程未知”，不要编造 Kevin 的手写步骤；训练使用清楚标明的**匿名模拟错误**。

### L3 同知识点变式、正确对照和逆向迁移（由诊断走向迁移）
- 每个真实错误模式/题族至少支持：**新数字或新情境找错案 + 正确对照案 + 改变未知量的逆向题**；合理时生成第二个不同错误陷阱。出题应换数量结构，不只是复制原卷换名称，不泄露后续答案。
- 已知最终求起始/变化、已知总量求每份/份数等逆向，均要有独立约束求解与代回两条验证路线；解唯一、条件够、单位一致。例：弹簧总长 = 原长 + 每千克伸长×千克数；正向与反向之间不是把式子倒序重写。
- **必须完成**已投递4包12案的白名单数学模型、精确算数、单元/浏览器测试和未知旧oracle重验证。参数变化同模型时**只需投递新匿名JSON**，不要求每新增一道错题再改React/服务端。
- 训练不能固定“每题都有错误”：对照题比例可按独立证据混入，且在正确推理案例应允许“没有需要修正的错误”。

### L4 自己解题 → 自己检查 → 自己纠错 → 延迟后无支架迁移（本轮核心新增）
- 给孩子**全新的可求解数学题**，不展示“小智的错误步骤”或预告正确与否。阶段内必须保存**不可变首次答案与可选原始解题步骤/思路**（包括空白/无法判断的区分）。
- 在**不给答案、不给对错标记、不透露首错位置、不提供相同题的标准解、不由家长替答**的前提下，进入**真实自查**：再次核对题意/单位/方向/数量关系，用反向代入、第二种算法、估算或实物/图示核验；至少有一个和题型对应的具体检查操作/证据，如填写反查式或指出对照条件。不能只勾“我已检查”三个框就算完成，也不能把点击“完成检查”直接当作已查对。
- 记录孩子自查后的**第二次答案/步骤**（可选择保留原答），必须有明确的“自查完成/仍不确定”提交；仅在两次答案及证据提交固定后揭示评判、正确答案与讲解。第一次错误、自己改正为正确，必须能在不借助反馈的情况下被准确判定；首次正确却被改错也要如实记录。
- 提示、条件图支架、家长代答均应单独记录并影响“独立”资格；给提示后可以继续学，但不得显示为无帮助的自主发现。手机/桌面返回、刷新和断网重试，不能覆盖冻结首答或错改历史。不要为 L4 直接复用 L1 的“知道别人有错”的judge流程。
- **延迟复测**：同一数学错误族的不同参数/未知量任务，默认在首次学习后 **1/3/7/14天**安排短量、不重复原题的无提示复核（以本地日期明确去重和到期逻辑；设备时间异常、安全上限、跨午夜/时区一致性可测试）。复测任务需能“到期提醒但不强迫今日全部做”；用户可暂停/调整，不能无限重复制造数据。若尚缺可验证迁移题，不得用原题记忆完成代替延迟掌握证据。
- L4 结果的“独立完成”须同时满足：无提示/无标准解暴露、首次答/自查证据可靠，后续新情境迁移及延迟复测达到明确规则；否则只标“本次正确/提示后纠正/尚待复测”，**禁止**单题正确宣称长期掌握。

## C. 案源与数据结构：维持真相和后向兼容

1. 建立清晰的模式实体：`errorFamilyId`（如平均求每份、基准＋增量、方向判断等）、`caseId/version`、`sourceKind`（匿名模拟/真实上传后脱敏重构/自主答题）、`questionVariantId`、`unknownRole`、`stage`（L1-L4）、`attemptId`，记录immutable `firstAnswer`、`firstReasoning`、`selfCheckActions`、`preFeedbackRevision`、`hintExposure`、`feedbackReleasedAt`、`reviewDueAt` 及适当评判快照。字段名字可因现有架构优化，但概念不能缺；版本/修订与来源关联必须稳定。
2. 兼容原 schemaVersion 1、旧四步判案、版本hash、旧待审/撤回/家长手工编辑、每日计划、首答、历史、口述家长核对、旧备份。采取**显式迁移/独立新命名空间**，禁止静默改变旧答题状态或用新解释回填旧结果；迁移必须幂等且可回滚。
3. 目前 200案/1000次调查/400天计划/3MiB 限额是真实存在的约束。本轮不启动整个跨站长期存储重构，但**必须**确保 L4 新的多阶段与延迟复测在合理规模下不会迅速误触上限或把旧库弄坏；提供容量测算、压力/边界测试、达到限额时的无丢失处理及以后迁移的清晰方案。不要把“不改平台”误解为允许用户的自查记录因限制被静默丢弃。
4. **答案防泄露**：L4 自查前公开API、网络响应、页面 DOM、可达客户端状态中均不得提前包含标准答案/正确性/标准错误定位/未来逆向题答案；旧L1阶段式release保持。所有判题以服务端或等效受控可信端为主，避免仅修改前端CSS隐藏。对远端匿名JSON不要信任 producer 字段自述；仅白名单参数 + 全字段生成 + 独立oracle能自动发布，复杂题需人工审核。
5. 公开 `detective-inbox` 只能含匿名数学条件与模拟步骤；**不得**上传原作业照片、姓名、学号、老师评语、原始笔迹、孩子真实步骤及学习记录。用户真实错题中只能提炼可复用的数学模式/脱敏条件。旧案来源事实和新生成步骤明确隔开。
6. 若现有 L4 题型暂不能支持开放文字的确定性判分，应合理区分“数字/选项自动核验”“数学解释由家长审核”，不把文本关键字命中冒充数学证明。

## D. 数学模板：前轮已欠任务必须一起闭环（不得再次留给下次）

## E. UX：要让 Kevin 真正会“自查”，而不靠大人不断提醒

1. 页面内明确区分“观察别人的做法”“尝试自己发现错误”“独立自查挑战/隔天复测”；不应把 4 个能力层级变成同时铺满的冗长导航。沿用现有简洁视觉与三年级理解能力，手机390px、平板768px、桌面1440px可使用，键盘与触控/无拖动替代方式可操作。
2. L4 未反馈前有清楚而**不暗示答案**的检查工具：题目问什么、单位有没有统一、反向条件能否成立、有没有只算增加量而非总量等。允许用纸笔或选择/填写检验过程，但最少留下一条可核对证据，不只“看一眼”。
3. 保留“错误→自改正确”的事实，并显示具体复盘，而不是奖励性恭维。区分“第一次正确”“独立自查改对”“自查仍未发现”“第一次对却自改错”“借助提示改对”；正确对照要如实告诉孩子本就无错。
4. 仍应支持一天5—8分钟的短练习，不强行把四层在同一日全部做完。复测队列到期可见且可延期；普通“今日3宗”不被无故重排；新增新案例即时可练；不因为延迟复测产生新的奖励积分。

## F. 指标与晋级：用可观察行为而非“我认真检查了”

至少提供模块内部、数学相关的统计和含义说明（不建立成长积分系统）：

- 首次作答正确率（首次对/有可评分首答）；自查后正确率（反馈前第二次答案对/有可评分自查提交）。
- **自查有效纠错率** = 首答错误且在**揭示答案前**自行改对 / 首答错误且完成自查的人数或尝试数；必须明确定义分母。另记“首答对却改错率”，防止为了改答案而改答案。
- 找错证据正确率、数学错误类型频次、迁移题正确率、1/3/7/14日独立复测通过率（仅统计真正到期且完成的样本；不到期和未做不可算失败也不可假装通过）。
- 对同一错误族，建议最低“独立自查前后证据 + 不同参数迁移 + 一次延迟无提示复测”才能标“有迁移证据”；这仍不是永久掌握。样本不足时写“证据不足/待复测”，不能报虚高掌握率。
- 旧勋章/钱包/积分不接入本指标；每日三枚旧上限既不删除也不新增奖励出口。若出现既有勋章不变性与新L4数据字段冲突，必须隔离新机制而非改变钱包。
