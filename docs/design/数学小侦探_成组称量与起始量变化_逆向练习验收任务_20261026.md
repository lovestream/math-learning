## 3. Codex 具体实现任务（范围只限新增题型，不扩建其他课程）

### R1：把现有4类新模板纳入可靠的确定性准入

在 `shared/detective-inbox.mjs` 中实施四个独立模板及其参数白名单。保持与现有六模板相同的**全字段确定性契约**：每一种参数组合必须由生成器推导出题干、匿名步骤、首错、正确答案、反查、三层提示、图示及依据；不是验证单一答案就放行。

**正向平均质量** `batch-average-mass-v1`：输入 `count`、`totalGrams`、`item`、`wrongDivisor`（错误案），`mode`。数学公式 `average = total/count`；模拟错误须可见且与正确结果不同。避免不可合理称量的绝对质量，必要时用“假设合计……”表述，不把模拟质量说成真实秤量。

**逆向平均质量** `mass-average-inverse-v1`：输入 `ask=total|count`、已知数量及每颗平均质量（或总质量和平均质量）、`mode`、`item`；求总量：`total=count*average`，求数量：`count=total/average`，数量为正整数，参考答案单位与问题一致；结果必须反乘/反除验证。

**弹簧最终长度** `spring-total-length-v1`：输入 `originalCm`、`mmPerKg`、`loadKg`、`mode`；总长毫米 `10*originalCm+loadKg*mmPerKg`。若要求厘米，转换后单位要一致。区别“伸长”和“总长”，首错不能标到正确的乘法步骤。

**弹簧逆向** `spring-reverse-v1`：两种模式 `ask=load|initial`；求重量 `loadKg=(finalMm-10*originalCm)/mmPerKg`；求原长 `originalMm=finalMm-loadKg*mmPerKg`；结果须非负、载重与伸长的比例符合题设、可反算。对于不整除的重量不要自动强行四舍五入；起始量未知时不得在题目中透出答案。

上述输入字段名与具体发布数据按**实际已入库 JSON**为准。为支持合理泛化，先在不改变既有投递字段的前提下增加参数边界与独立校验，不能靠硬编码12宗题目标题冒充模板实现。
